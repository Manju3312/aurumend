2. THE DUAL-LAYER SOLUTION: IMMUNIX
--------------------------------------------------------------------------------
Immunix provides a revolutionary two-path sovereign defense against API drift:

PATH 1: IN-PROCESS RUNTIME IMMUNITY (@aurumend/shield)
- Transparent, ultra-lightweight client middleware with <1.2ms P99 latency overhead.
- Catches runtime schema drift and breaking changes in-process.
- Activates fail-open resilience to prevent host application crashes.
- Zero Request Body Retention (100% PII and citizen data privacy / SOC-2 compliant).

PATH 2: AUTONOMOUS BUILD-TIME HEALING & CONTRACT VERIFICATION
- Upstream OpenAPI Harvester continuously monitors vendor schema deprecations.

- Runs typechecks (`tsc --noEmit`) and contract tests until 100% assertions pass.
